# 09. 技术债与风险登记表

| ID | 风险 | 级别 | 触发条件 | 影响 | 缓解措施 |
|---|---|---:|---|---|---|
| R-01 | API Key 明文存储 | 高 | DB 泄漏、导出、备份、误分享 | 账户/API 费用风险 | Keychain、导出排除、日志脱敏。 |
| R-02 | 保存失败静默 | 高 | DB 写入失败、重复约束、导入异常 | 用户误以为保存成功 | 移除 `try?`，统一错误 UI。 |
| R-03 | stream 取消后 UI/DB 不一致 | 高 | 用户点击停止、网络断开 | 回复消失/叙事断裂 | 部分回复落库或明确丢弃。 |
| R-04 | 向量孤儿数据 | 中高 | 清空数据/删除角色 | 隐私清理不完整、检索污染 | 显式清理 `memory_embedding`。 |
| R-05 | 分层漂移扩大 | 中高 | Codex/多人继续加功能 | 维护成本上升、循环依赖 | 架构边界测试、App shell 收口。 |
| R-06 | 导入导出未完成 | 中高 | 用户换设备/重装/备份 | 数据无法迁移 | Snapshot 导出导入。 |
| R-07 | 资源依赖测试阻塞 CI | 中 | 模型权重不在仓库/CI | 测试无法稳定运行 | mock/skip/集成测试拆分。 |
| R-08 | Prompt 注入 | 中 | 导入第三方角色卡/世界书 | 角色失控、规则被覆盖 | 数据块边界、防注入测试。 |
| R-09 | Token 预算误差 | 中 | 使用不同 provider/model | 请求失败、历史丢失 | per-model safety margin、截断。 |
| R-10 | 默认项无 DB 约束 | 中 | 并发/迁移/手工恢复 | 默认 endpoint/model 不确定 | partial unique index。 |
| R-11 | 记忆污染 | 中 | API 提取错误、冲突记忆 | 角色长期偏离 | 记忆管理 UI、来源追踪、禁用。 |
| R-12 | 网络错误过长/泄密 | 中 | Provider 返回敏感 body | 弹窗/日志泄漏 | ErrorSanitizer、截断、脱敏。 |
| R-13 | 启动 fallback 掩盖 DB 故障 | 高 | live DB 打开失败 | 用户以为数据丢失 | 启动错误页，不切 preview。 |
| R-14 | 世界书解析脆弱 | 中 | 导入复杂 Markdown | 条目丢失/错误触发 | Parser 升级、导入 preview。 |
| R-15 | 缺 CI/lint/format | 中 | 频繁协作 | 质量波动 | GitHub Actions、SwiftFormat、SwiftLint。 |

## 风险关闭准则

风险不能只靠“代码改了”关闭，必须满足：

1. 有对应测试。
2. 有用户可见行为或文档说明。
3. 对高风险项，有回归测试或 CI 规则。
4. 对数据迁移项，有旧库迁移测试。
