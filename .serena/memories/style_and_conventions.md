Use Swift 6 conventions from AGENTS.md and .github/instructions. Prefer struct unless reference semantics are required; ViewModels are class + @Observable; async work uses async/await and AsyncThrowingStream; no Combine or callback-style APIs. Errors are typed enum + LocalizedError. User-facing strings belong in Localizable.xcstrings. Database records are struct + Codable + FetchableRecord + PersistableRecord; migrations are append-only via DatabaseMigrator and must not reference Record types. Architectural rules: App -> Features -> Core -> Shared only, no reverse dependency, no direct Feature-to-Feature imports, and ViewModels receive dependencies via init.
