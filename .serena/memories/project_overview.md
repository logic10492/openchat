OpenChat is a docs-first iOS 17+ roleplay chat app targeting Swift 6, SwiftUI, MVVM with @Observable, Swift Concurrency, GRDB + SQLite, URLSession AsyncBytes, and a four-layer architecture: App -> Features -> Core -> Shared. Current repository state is documentation-only: AGENTS.md plus arch/ docs and .github instruction files; no Xcode project or source tree exists yet. Key modules planned in docs: Core/Networking, Core/PromptEngine, Core/ContextManager, Core/Database; Features/Chat, CharacterCard, WorldBook, Conversation, Settings. Roadmap is phased from basic app skeleton to full production-quality feature set.
